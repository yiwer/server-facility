## Contract and threat boundaries

- Startup requires trusted issuer, exactly one audience and canonical resource URI. Production uses HTTPS with no URI userinfo/query/fragment. Explicit local mode additionally permits loopback HTTP; local+prod fails. The same rule applies to discovered outbound JWK URIs. Public-key-location is outside this template policy.
- Boot owns the lazy decoder. Standard issuer/audience/type checks remain; RS256 is explicitly selected, expiry and nonblank normalized subject are required, `nbf` uses the standard 60-second tolerance. Real signatures come from JDK RSA/SHA256withRSA, independently of the production Nimbus verifier. No raw JWT parser or identity provider was added.
- Actor is issuer plus normalized subject. The actual standard processor hook sees numeric `sub:42` as String `"42"` before Spring's mapped-claims converter; string `sub:"42"` has the same Actor. Both wire cases are permanent HTTP/processor-hook goldens. A trusted issuer must own an unambiguous namespace and emit String subjects. This is not strict original-JSON claim-type enforcement.
- Missing/invalid credentials401, authenticated scope denial403, unavailable authentication infrastructure503. Safe ProblemDetail and fixed Bearer headers compose public FacilityHttpErrors; token/cause/upstream body and attacker Host/forwarding values are not echoed. Header credentials only; query tokens are ignored. Health and canonical protected-resource metadata are public; unlisted business routes are denied.
- Keys are cached under standard Nimbus policy (resolved10.9.1 `DEFAULT_CACHE_TIME_TO_LIVE=300000ms`; `DEFAULT_CACHE_REFRESH_TIMEOUT=15000ms`, confirmed from the exact jar's public constants). Security's builder disables refresh-ahead/rate-limited wrapping and uses standard cache behavior. Cached matching keys can work during an outage; a needed failed refresh503; successful refresh with missing key401. Rotation tests publish A→A+B→B and prove these cases. Immediate revocation is not promised.
- Every outbound metadata/JWK body is limited to65,536 bytes before parsing; each fetch has a total body-inclusive deadline (default2s, configurable positive≤10s), redirects rejected. This is a per-fetch budget, not a promise that complete first-token discovery or concurrent cache refresh always finishes in2s. Nimbus's own cache-refresh waiting applies. HTTP connection count64, accept queue32, platform workers32; application platform executor2–8/queue32, virtual executor concurrency8. Header budget8KiB, async request default5s. No throughput or arbitrary long-stability claim is made.
- Standard DelegatingSecurityContextRunnable owns identity restoration. The private Micrometer registry propagates only the application's configured trace key. Micrometer1.2.1 does not atomically roll back partially installed accessors; the template's local finally guard handles that key, preserving the original exception and suppressed rollback exception. Callable uses standard MVC integration; DeferredResult propagation applies only to producers started by this application executor. External arbitrary threads must receive Actor explicitly.
